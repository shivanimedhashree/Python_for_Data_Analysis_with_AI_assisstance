# Project 1 – Superstore Dataset Analysis

### About the Dataset

The Superstore dataset contains business-related information such as customer details, orders, products, sales, discounts, and profits.

The dataset was loaded into Python using Pandas and analysed using different data analysis operations.

The dataset contains **10,194 records and 21 columns**.

### Data loading and Inspection

The dataset was loaded using the Pandas read_csv() function. The data was insepcted to understand:

* The first few rows
* The last few rows
* The columns imn the dataset
* The structure and size of the dataset
* Different categories and values present in the data

### Analysis Performed

The analysis includes:

* Sales and profit analysis
* Category and sub-category analysis
* Regional analysis
* Customer segment analysis
* Shipping mode analysis
* Discount analysis
* Profit margin analysis
* Filtering, sorting, grouping, and aggregation using Pandas

# Project 2 – Airline Flights Dataset Analysis

### About the Dataset

The Airline Flights dataset contains information about airlines, flights, source and destination cities, departure and arrival times, stops, travel class, duration, days left, and ticket prices.

* Displaying first five rows.

* Checking the number of rows and columns.
* Examining columns names.
* Inspecting the structure and data types.
* Generating descriptive statistics.

### Analysis Performed

The analysis includes:

* Airline analysis
* Flight count analysis
* Source and destination city analysis
* Departure and arrival time analysis
* Stops analysis
* Travel class analysis
* Flight duration analysis
* Days-left analysis
* Ticket price analysis
* Grouping and aggregation using Pandas

# Visualizations

Various data visualization techniques were used in the project to present the analysed data in a clear and understandable way.

The visualizations include:

### 2D Visualizations

* **Bar Charts** – Used to compare values across different categories.
* **Line Charts** – Used to show trends and changes over time.
* **Histograms** – Used to show the distribution of numerical data.
* **Scatter Plots** – Used to study relationships between two numerical variables.
* **Box Plots** – Used to compare distributions and identify the spread of data.
* **Violin Plots** – Used to show the distribution and variation of data across categories.
* **Heatmaps** – Used to represent relationships and correlations between variables.
* **Count Plots** – Used to show the number of observations in different categories.
* **KDE Plots** – Used to visualize the distribution of numerical variables.
* **Rolling Mean Line Charts** – Used to observe smoothed trends in time-based data.

These visualizations were created using **Matplotlib and Seaborn**.
